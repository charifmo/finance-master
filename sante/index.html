Une page web ne peut pas lire Samsung Health toute seule (Android l’interdit aux sites). La petite appli gratuite HC Webhook le fait pour elle : elle lit Samsung Health (via Health Connect) et envoie ici vos pas, calories, sommeil, poids et fréquence cardiaque — toute seule toutes les heures, ou d’un appui sur son widget « Synchroniser ».

  1. Samsung Health → ≡ → Paramètres → Health Connect : autorisez le partage (pas, calories, poids, sommeil, fréquence cardiaque).
  2. Installez HC Webhook (Play Store). Ouvrez-la → Accorder les autorisations : Pas, Calories actives, Poids, Sommeil, Fréquence cardiaque, Fréquence cardiaque au repos ; acceptez aussi l’autorisation d’arrière-plan.
  3. Ici : {{ configAuto.message }}

    En-têtes (JSON)

    Copie automatique impossible ici : sélectionnez le texte et copiez-le.

  4. Dans HC Webhook → Webhooks : ajoutez l’adresse → Modifier les en-têtes → onglet JSON → collez → Appliquer JSON.
  5. Quand synchroniser → Intervalle 60 min (ou Programmé, par ex. 8 h et 21 h) → enregistrez. Laissez les pas et calories en Quotidien (réglage par défaut).
  6. Votre bouton : appui long sur l’écran d’accueil du téléphone → Widgets → HC Webhook → « Synchroniser ». Un appui = vos données arrivent ici ; revenez sur cette page, elle se met à jour.

Pas à pas sur le téléphone Samsung (2 minutes)
  1. Samsung Health → menu ≡ (ou ⋮) → Paramètres → « Télécharger les données personnelles » → Télécharger, puis confirmez avec votre compte Samsung.
  2. Ouvrez l’appli Mes fichiers → Téléchargements (ou Stockage interne › Download) → dossier Samsung Health.
  3. Appui long sur le dossier samsunghealth_… (le plus récent) → ⋮ Plus → Compresser → OK. Un fichier samsunghealth_….zip apparaît à côté.
  4. Ici, touchez « 📲 Importer l’export » et choisissez ce .zip. C’est tout : pas besoin d’ouvrir les sous-dossiers files et jsons.

Sans compresser : ouvrez le dossier samsunghealth_… dans le sélecteur, Tout sélectionner (les fichiers .csv sont à sa racine, à côté de files et jsons), puis validez. Ou « 📁 Choisir le dossier entier » si votre téléphone le propose.

Réimporter un export plus récent met les jours à jour sans rien dupliquer. Le journal reprend la dernière année ; les pesées, tout l’historique.

Autre application ou tableur : un CSV avec une colonne date (AAAA-MM-JJ) et au choix steps / pas, active_calorie / kcal, weight / poids, resting_heart_rate, sleep_minutes.
